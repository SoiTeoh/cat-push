# Cat Push（小猫：鬼点子生成中）

一款基于 **Vite + TypeScript + Matter.js + HTML5 Canvas 2D** 的轻量级竖屏物理恶作剧小游戏。  
玩家扮演一只在桌面边试探的小猫：趁铲屎官背对专注做事时把桌上的纸巾盒、圆珠笔、马克杯和玻璃水壶推到桌沿甚至推下地板；在铲屎官回头前松手秒变 `^ ◡ ^` 闭眼假睡，挑战 60 秒破坏账单最高分。

## 核心玩法

- **桌面推物与悬边倍增**：物体质心接近桌沿且倾斜角超过 `6°` 时进入 `×2` 悬边态；持续悬停超过 `1.5s` 升级为 `×3` 极限挑衅倍率。
- **铲屎官回头监听状态机**：`RELAXED -> WARNING (0.9s) -> WATCHING (1.8~2.5s)`。噪声越高，铲屎官回头越频繁；在 `WATCHING` 期间继续推物、或仍有物体在桌上滚动/坠落都会被抓包，扣除 1 颗红心（共 3 颗）。
- **4 种不同物理材质物品**：纸巾盒（轻飘摩擦）、圆珠笔（易滚动）、马克杯（重且稳定）、玻璃水壶（高重心高价值）。
- **波次补货与限时账单**：桌面清空后自动补充下一波物品；60 秒结束或 3 颗红心耗尽后生成破坏账单并保存历史最高分。

## 操作方式

- **触屏 / 鼠标**：按住画面左半区向左移动，按住右半区向右推进；松手在 `0.12s` 内切换为假睡闭眼。
- **键盘**：`A` / `←` 向左，`D` / `→` 向右，`Space` 高风险轻拍一爪；结算页按 `R` 或 `Enter` 再来一局。
- **调试视图**：在 URL 后添加 `?debug=1` 可查看刚体边界、桌沿距离、悬边角度、状态机阶段与噪声值。

## 本地开发与验证

```bash
npm install

```

## 目录结构

- `src/config/tuning.ts`：视口尺寸、物理步长、小猫参数、悬边倍率、铲屎官状态机与物品数值配置
- `src/game/rules.ts`：纯 TypeScript 规则逻辑（悬边倍率、状态机推进、破坏账单统计）
- `src/game/world.ts`：Matter.js 刚体桌面世界、物品生成、推物与拍打物理交互
- `src/game/audio.ts`：Web Audio API 合成音效（提示音、拍打、碎裂、抓包）与静音控制
- `src/render/painter.ts`：Canvas 2D 矢量场景、表情动画、HUD、粒子与调试叠层渲染
- `src/main.ts`：主循环、DPR 自适应、指针/键盘输入与 `localStorage` 最高分记录
- `tests/rules.test.ts`：Vitest 单元测试
